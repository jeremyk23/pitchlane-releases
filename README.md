# PitchLane releases

Installers for PitchLane, pitch editing for vocals in Ableton Live (Max for Live, Apple silicon).

- **Install / update:** download the latest `PitchLane-x.y.z.pkg` from [Releases](../../releases). Quit Live first.
- **Uninstall:** [Uninstall-PitchLane.pkg](../../releases/latest/download/Uninstall-PitchLane.pkg). Your sets keep their PitchLane edits.
- **Problems:** click **Report a problem** at the top of PitchLane's editor.

PitchLane checks `updates.json` here to tell you when a new version is out.
